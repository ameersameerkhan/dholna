# Scene artwork

Dholna expects four paired JPEG scene files:

| File | Role |
| --- | --- |
| `day.jpg` | Desktop / landscape day scene |
| `night.jpg` | Desktop / landscape night scene |
| `day-mobile.jpg` | Mobile / portrait day scene |
| `night-mobile.jpg` | Mobile / portrait night scene |

For remixes, aim for roughly **16:9** landscape artwork and **9:16** portrait artwork. Keep the day and night versions closely aligned in camera angle and composition so switching modes feels like the same journey at a different time.

A good scene leaves enough quiet space for Dholna's interface, keeps the train-window perspective readable, and treats mobile as a considered recomposition rather than a simple centre crop.
